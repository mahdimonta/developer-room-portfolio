تغییرات محتوایی:
- هیچ فایل سورس، تنظیمات، دارایی یا سند موجود ویرایش نشده است.
- فقط موارد موقت/قابل‌بازسازی بالا از آرشیو خروجی کنار گذاشته شده‌اند.

نحوه نصب وابستگی‌ها پس از استخراج:
1) Node.js را نصب کنید.
2) در پوشه اصلی پروژه دستور زیر را اجرا کنید:
   npm ci
3) اجرای محیط توسعه:
   npm run dev
4) ساخت خروجی انتشار:
   npm run build

نکته:
- پوشه dist در خروجی حفظ شده و برای انتشار مستقیم قابل استفاده است.
- برای توسعه یا ساخت مجدد dist، وابستگی‌ها باید با npm ci نصب شوند.
- این پاک‌سازی تضمین نمی‌کند که برنامه بدون اجرای تست در محیط مقصد کاملاً بی‌خطا باشد؛
